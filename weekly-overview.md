# Program at a Glance — Six-Week Onboarding & Training Structure

*Sanitized one-page summary of the redesigned curriculum. See `training-program-redacted.md` for full detail.*

Six weeks, each building toward independent ticket work and a first certification.

| Week | Focus | What They Do |
|---|---|---|
| 1 | Accounts, Introduction, Ticketing Platform | Log into core accounts; HR onboarding and building tour; meet the team; learn ticket handling, SLA priorities, and the ticketing platform; credit-hold and agreement processes; team-chat channel structure; begin vendor training |
| 2 | Directory Services, Group Policy, Permissions | Directory services (users, groups, OUs, group policy, permissions); begin cloud-fundamentals certification coursework |
| 3 | Cloud Suite, Modern Workplace, Event Logs, MFA Overview, Core Platforms | Cloud productivity suite admin tasks; modern workplace tools; event log review; MFA overview; continue certifications; quick intros to the RMM/monitoring and IT documentation platforms |
| 4 | Automated Alerting and Live Ticket Work | Learn automated-ticket categories; start working real assigned tickets under supervision |
| 5 | Endpoint Security, Email Security, Identity/MFA (Deep Dive) | Hands-on EDR (scan + review results, response actions) and MDR (reading incident reports) training; applied secure-email-gateway triage; hands-on identity/MFA training |
| 6 | Performance Metrics, Network Security Certification | Learn the performance metrics tracked and where to view them; complete the network-security foundational certification; finalize first certification plan |
